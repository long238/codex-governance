# Playbook 索引

Playbook 保存已经验证且可复用的非显然排障路径，帮助后续任务从症状快速定位到证据。它不记录未验证猜测，也不替代当前实现或测试说明。

## 准入条件

只有同时满足以下条件才创建或更新条目：

- 问题已经实际解决；
- 根本原因已经确认；
- 修复和关键验证已经通过；
- 问题有合理复现概率；
- 排查路径对未来同类问题具有明显价值。

普通拼写、显而易见语法错误、一次性手误、根因未确认或仅有临时绕过的问题不得收录。

默认只沉淀当前任务中新验证的经验，不批量回填历史。用户明确要求历史整理时，仍须逐项满足上述条件；在当前已批准任务内记录满足条件的经验，不为记录本身重复申请审批。

## 条目内容

每份 Playbook 建议包含：

- 可识别的症状与适用范围；
- 不适用情形；
- 最小只读检查顺序；
- 已确认根因及证据；
- 修复方式和安全边界；
- 已执行验证与仍未覆盖的环境；
- 相关当前事实文档、测试或 Decision。
